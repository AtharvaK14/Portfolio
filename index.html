Test Observability: AI Root-Cause Agent

3Failure verdicts: app bug, flaky test, environment

Ingests Playwright, Cypress, PyTest and Selenium results and uses Claude to diagnose why each failure happened (app bug, flaky test, environment, test data, infrastructure or external dependency) from measured evidence, not the error string alone.

  • Python
  • FastAPI
  • SQLAlchemy
  • PostgreSQL
  • Claude API
  • Docker
  • GitHub Actions
Details
  • 167 tests, mypy --strict clean, verified end to end against real Playwright, Cypress and PyTest output.
  • Builds diagnostic evidence per failure (30-run pass/fail history, commit-range check, cross-framework blast radius, duration against baseline, error-fingerprint clustering) before the model forms an opinion.
  • The agent investigates with 5 retrieval tools across up to 4 turns, then returns a schema-validated verdict through a strict tool call instead of parsed text.
  • Two classifiers scored against seeded ground truth: a confidence-capped rule-based heuristic as the control group, and Claude. Accuracy claims are falsifiable, not asserted.
  • Deterministic, LLM-free hash-based clustering collapses hundreds of red tests into the handful of real underlying problems.
  • Backend and agent are complete; the React dashboard is the next milestone.
